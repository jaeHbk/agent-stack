---
description: Draft a self-contained contract for a coding or review task
---

Create a task contract for the current request using this exact structure:

```text
Objective:
Acceptance criteria:
Repository and working directory:
Relevant paths:
Out of scope:
Constraints:
Validation commands:
Expected report:
```

Resolve facts from the repository first. Keep the contract self-contained and
omit unrelated conversation history.
