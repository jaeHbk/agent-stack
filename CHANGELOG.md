# Changelog

## v0.1.0-beta.1 - 2026-07-31

- Added resumable one-command onboarding for local, hybrid, and cloud profiles.
- Added checksum-pinned local inference, rollback, diagnostics, export/restore,
  and fail-closed dependency auditing.
- Added repository-owned Pi workflow guidance and removed the unlicensed
  third-party Pi customization dependency.
- Added public-release licensing, attribution, security policy, secret scanning,
  and modern pinned GitHub Actions.

This beta has been exercised on a 36 GiB Apple Silicon Mac. Source installation
is supported; no prebuilt runtime binary is included in this release.
