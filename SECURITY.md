# Security Policy

## Supported Versions

Only the latest tagged beta or stable release is supported. This is a
single-user development stack, not a hardened multi-tenant service.

## Reporting a Vulnerability

Use [GitHub private vulnerability reporting](https://github.com/jaeHbk/agent-stack/security/advisories/new).
Do not include credentials, tokens, private prompts, diagnostics, or exploit
details in a public issue.

Include the affected revision, profile, macOS version, reproduction steps,
impact, and any proposed mitigation. The maintainer will acknowledge a report
as availability permits and coordinate disclosure after a fix is available.

For the trust model, credential boundaries, supply-chain controls, and residual
risks, read [`docs/SECURITY.md`](docs/SECURITY.md).
